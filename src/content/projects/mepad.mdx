<LogEntry title="Day 1: Layout Design" date="Jan 3, 2026">
  <ImageGrid images={[{ src: '/assets/MePad_Layout.jpg', alt: 'MePad Layout Design' }]} />

  Day one was the day I decided to start the project on a whim. I focused on researching and taking inspiration from online resources like Bilibili.

  I set the initial layout for the keypad using [keyboard-layout-editor.com](http://keyboard-layout-editor.com). The plan is to have 9 custom regular switch keys and 2 scroll knobs—one for audio controls and one for scrolling through webpages or Premiere Pro timelines.
</LogEntry>

<LogEntry title="Day 2: PCB Schematics & Firmware" date="Jan 5, 2026">
  <ImageGrid images={[
    { src: '/assets/MePad_Matrix.jpg', alt: 'MePad Switch Matrix' },
    { src: '/assets/MePad_Schematic.png', alt: 'MePad Schematic' },
  ]} />

  Today was a big day for learning and design. I dived into the electrical engineering side of keyboards:

  - Learned how to optimize microcontroller connections using a switch matrix.
  - Implemented diodes to avoid input ghosting.
  - Built initial keyboard firmware with [kbfirmware.com](https://kbfirmware.com).
  - Designed the PCB footprint using Autodesk Fusion 360 (Knobs: Top 15mm, Bottom 32mm).
  - Finished PCB schematics with EasyEDA centered on the ATmega32U4 microcontroller.
</LogEntry>
